# Simple Shopping List

## Приложение Простой лист покупок. 

## Цель приложения: 
 Изучение и практическое применение современных технологий Android разработки.

## Использованные технологии:
1. Язык - Kotlin
2. Архитектура - MVVM.
3. UI - XML
4. Хранение данных – Room
5. Асинхронная работа - Kotlin Coroutins.
6. Dependency injection - Dagger 2

## Использованные API:
1. Работа с сетью в данном приложении не реализована
